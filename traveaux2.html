Intranet collaborateurs (MDL)

Développer le front-end et une partie du back-end d'un intranet qui facilite les échanges entre les collaborateurs d'une entreprise en pleine croissance.

  • PHP orienté objet
  • MySQL
  • HTML
  • CSS
  • MCD / MLD
Voir le code

Le contexte

La Maison des Ligues (MDL), une structure de taille moyenne, vient de recruter de nombreux collaborateurs. La direction veut une plateforme interne pour faciliter et encourager les relations entre collègues. En tant que développeur du pôle technique, j'étais chargé du front-end et d'une partie du back-end pour le traitement des requêtes côté serveur.

Maquettes

Fonctionnement

  • Après connexion, la page d'accueil présente un collègue choisi au hasard.
  • Le bouton « Dire bonjour à quelqu'un d'autre » affiche un autre collègue.
  • Une page liste tous les collaborateurs sous forme de cartes, avec leurs informations.
  • Un clic sur sa photo de profil ouvre la modification de ses informations, identifiants compris.
  • Après déconnexion, plus aucune page de l'intranet n'est accessible.

Base de données

Contraintes techniques du sujet

  • HTML5, CSS3, JavaScript et PHP orienté objet (classes et instances).
  • Police « Open Sans » et couleurs du thème définies dans des variables CSS.
  • Code HTML valide selon le W3C et respectant les règles d'accessibilité (WAI, WCAG).
  • Rendu publié sur GitHub, avec une structure claire, un README et un .gitignore.
