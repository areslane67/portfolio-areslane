BrainBurst

An interactive quiz app built with React and TypeScript: quizzes by theme and difficulty level, a score, and a "sudden death" mode where a single mistake ends the game.

Context

BrainBurst is a group project from the Master's program, built by three people in three weeks. It had two goals: go deeper into React and its Hooks, and learn how to run a team project in conditions close to a professional environment.

Problem

The task was to design a fun, educational quiz app that felt complete and pleasant to use:

  • several quizzes sorted by theme and difficulty level, with progress and score tracking;
  • a "hardcore" mode where a single mistake ends the game;
  • a smooth, responsive interface, with clean, well-structured and documented code;
  • a modular structure, so new quizzes, themes and features are easy to add.

All of it with several people working on the same codebase, which called for a clear way of organizing the work.

Approach

  • Visual design: wireframes, zoning, then mockups in Figma, plus a style guide, before writing any code.
  • Work split: each member owned one part: the quiz logic (steps, progress, score), displaying the questions and navigation, the results screen, and the overall design with visual interactions.
  • Git workflow: one branch per feature, pull requests and code reviews before every merge, with tasks organized in Trello.
  • Development: React and TypeScript with Hooks (useState, useEffect, useMemo…), and React Router to move between screens (mode, theme and difficulty selection, countdown, quiz, results).
  • Questions: loaded from the public Open Trivia DB API, based on the chosen theme and difficulty.
  • Two game modes: "classic", a set of 10 timed questions, and "sudden death", where the game stops at the first mistake.

Result

The app is live. In classic mode, players pick a theme (general knowledge, history, movies, sports, science and nature, or a mix of all themes) and a difficulty level, then answer the questions and get their score.

This project gave me hands-on practice working with others on the same codebase using branches, pull requests and reviews, and turning Figma mockups into a React interface.

My role: developing web interfaces and the API, managing and organizing the project, and designing the app's mockups in Figma.
