Employee intranet (MDL)

Building the front end and part of the back end of an intranet that makes communication easier between the employees of a fast-growing company.

  • Object-oriented PHP
  • MySQL
  • HTML
  • CSS
  • Data modeling (MCD / MLD)
View the code

Context

The Maison des Ligues (MDL), a mid-sized organization, has just hired a large number of new employees. Management wants an internal platform to make it easier for colleagues to connect and to encourage relationships between them. As a developer on the technical team, I was responsible for the front end and part of the back end, handling server-side request processing.

Mockups

How it works

  • After logging in, the home page features a randomly selected colleague.
  • The "Say hi to someone else" button displays another colleague.
  • A page lists all employees as cards, along with their details.
  • Clicking your profile picture lets you edit your details, including your login credentials.
  • Once logged out, none of the intranet pages can be accessed.

Database

Technical requirements of the brief

  • HTML5, CSS3, JavaScript and object-oriented PHP (classes and instances).
  • "Open Sans" font and theme colors defined in CSS variables.
  • W3C-valid HTML that follows accessibility guidelines (WAI, WCAG).
  • Deliverable published on GitHub, with a clear structure, a README and a .gitignore.
