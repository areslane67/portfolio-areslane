Budget Tracker

A personal budgeting app built with React and TypeScript: income and expenses, balance, statistics, filters and automatic saving in the browser.

Context

Budget Tracker is a hands-on React assignment designed to take 8 hours. The brief: build a personal budgeting app with React and TypeScript while practicing collaborative work with Git and GitHub. The assignment is meant to be done in pairs, organized around feature branches.

Problem

The app had to let users:

  • add income and expenses;
  • see the total balance along with statistics;
  • filter transactions (all, income only or expenses only);
  • find their data again after reloading the page, thanks to localStorage.

Optional extras were possible: a chart, advanced statistics, stronger form validation and a responsive design.

Approach

  • Component breakdown: a form (TransactionForm), a list and a transaction row (TransactionList, TransactionItem), balance and statistics (Balance) and filters (Filter), with one CSS file per component.
  • Centralized state: transactions and the active filter live in App with useState and are passed down to components as props.
  • Typing: each transaction has a TypeScript type (ID, title, amount, income or expense type, date).
  • Calculations: totals, balance and filtering with the filter(), reduce() and map() methods.
  • Persistence: useEffect loads transactions from localStorage on startup and saves them on every change, with handling for corrupted data.
  • Validation: title between 1 and 100 characters, amount between 0.01 and 999,999.99, no future dates, and a confirmation message after each new entry.
  • Git: one branch per feature (feature/form, feature/list, feature/balance…) and commit messages following the Conventional Commits format.

Result

All the core features of the assignment are in place: adding and deleting transactions, a list sorted by date, the balance, filters and automatic saving. So are the extras: an income vs. expense distribution bar, savings rate and average per transaction, advanced validation and a responsive design (mobile, tablet and desktop).

The code is available on GitHub and the app runs locally with Vite. This assignment helped me strengthen my React and TypeScript fundamentals (components, props, state, effects) and practice a structured Git workflow, all within a tight time frame.
