Budget Tracker

Une application de gestion de budget personnel en React et TypeScript : revenus et dépenses, solde, statistiques, filtres et sauvegarde automatique dans le navigateur.

Contexte

Budget Tracker est un TP (travail pratique) de React prévu pour durer 8 heures. Le sujet : réaliser une application de gestion de budget personnel en React et TypeScript, tout en pratiquant le travail collaboratif avec Git et GitHub. Le TP prévoit un travail en binôme, organisé en branches de fonctionnalités.

Problème

L'application devait permettre de :

  • ajouter des revenus et des dépenses ;
  • voir le solde total avec des statistiques ;
  • filtrer les transactions (toutes, revenus ou dépenses) ;
  • retrouver ses données après un rechargement de la page, grâce au localStorage.

Des bonus étaient possibles : un graphique, des statistiques avancées, une validation plus poussée du formulaire et un design responsive.

Démarche

  • Découpage en composants : formulaire (TransactionForm), liste et ligne de transaction (TransactionList, TransactionItem), solde et statistiques (Balance) et filtres (Filter), avec une feuille CSS par composant.
  • État centralisé : les transactions et le filtre actif sont gérés dans App avec useState, puis transmis aux composants par les props.
  • Typage : une transaction est typée en TypeScript (identifiant, titre, montant, type revenu ou dépense, date).
  • Calculs : totaux, solde et filtrage avec les méthodes filter(), reduce() et map().
  • Persistance : useEffect charge les transactions depuis le localStorage au démarrage et les sauvegarde à chaque modification, avec une gestion des données corrompues.
  • Validation : titre de 1 à 100 caractères, montant compris entre 0,01 et 999 999,99, pas de date dans le futur, et un message de confirmation après chaque ajout.
  • Git : une branche par fonctionnalité (feature/form, feature/list, feature/balance…) et des messages de commit au format Conventional Commits.

Résultat

Toutes les fonctionnalités principales du TP sont en place : ajout et suppression de transactions, liste triée par date, solde, filtres et sauvegarde automatique. Les bonus aussi : barre de répartition entre revenus et dépenses, taux d'épargne et moyenne par transaction, validation avancée et design responsive (mobile, tablette et ordinateur).

Le code est disponible sur GitHub et l'application se lance en local avec Vite. Ce TP m'a permis de consolider les bases de React avec TypeScript (composants, props, état, effets) et de pratiquer un workflow Git structuré, le tout dans un temps limité.
